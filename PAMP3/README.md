## Struktur

Terdapat tiga composable yang diletakkan pada folder 'components':
- 'ProfileHeader': memuat foto profile dan nama.
- 'InfoItem': baris info (ikon, label, nilai).
- 'ProfileCard': Kartu berisi bio dan 'InfoItem'.

'ProfileScreen' menyusun semua composable, dan dipanggil melalui 'App.kt'.

## Cara Run
1. Buka file `app/shared/src/commonMain/kotlin/com.example.pamp2/App.kt`.
2. Klik ikon hijau **Run**, dan pilih desktopApp.
